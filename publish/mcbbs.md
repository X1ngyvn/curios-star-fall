## 二、正文（直接粘贴）

```text
【模组名称】星陨饰品栏 / Star Fall
【模组版本】1.3.0
【适用版本】Minecraft 1.20.1 · Forge 47.x
【前置模组】Curios API 5.7.0+（5.12.1 / 5.14.1 实测可用）
【授权方式】All Rights Reserved（整合包可直接收录）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 模组简介

这不是又一个「加一堆新饰品」的模组，而是接管「栏位数量」本身。

用一颗星陨开个头，之后每过一个游戏日，你的饰品栏就长一格。
想让节奏慢一点？把它改成每 3 天 +1。
想在第 7 天额外送一个戒指位、第 30 天送两个项链位？
一行配置就能写清楚。

■ 玩法流程

1. 击杀末影龙拿到龙蛋；
2. 用【4 个下界之星 + 1 个龙蛋】合成「星陨」（十字摆放，龙蛋在正中心，四个下界之星围绕）；
3. 手持星陨右键使用 —— 物品消失，解锁史诗成就「渐强」，从当天开始计时；
4. 之后每过一个游戏日，聊天栏提示：
       渐强:饰品栏+1(累计1)
   Curios 界面里对应的原生栏位就多一格；
5. 想要「什么都能装」的通用栏位时，用命令把一个原生栏位换过去：
       /dailyslot convert @s curio 1

※ 没用过星陨的玩家不会获得任何栏位，也不会累计天数，服务器里不会出现「老玩家一进来就几十格」的情况。

■ 发放的是原生栏位

head 首饰 / necklace 项链 / ring 戒指 / belt 腰带 / body 胸饰
charm 护符 / hands 手饰 / bracelet 手镯 / curio 饰品

因为发的就是 Curios 的原生栏位，所以：
· GUI 图标、槽位排版、分页 —— 与原生完全一致
· 物品提示、死亡掉落规则、属性加成结算 —— 全部走 Curios 自己的逻辑
· 与其他饰品模组共存时，本模组只做「取较大值」合并，不会覆盖别人给的栏位

另外保留了一个本模组自建的「通用栏位」（可放任意物品），但它不再自动发放，
需要用上面的 convert 命令手动把原生栏位换过去 —— 需要的时候再换，不需要就一直是原生栏位。

■ 配置文件

路径：config/curios-star-fall-common.toml

# 里程碑：到第 N 天一次性发放（默认空 = 只有每日规则）
milestones = []

[general]
    intervalDays = 1        # 每几个游戏日发放一次；0 = 关闭每日发放
    slotsPerGrant = 1       # 每次发放几个
    defaultSlot = "curio"   # 每日发放用哪种栏位
    maxSlotsPerType = 32    # 每种栏位最多发放多少；0 = 不限
    announce = true         # 发放时是否在聊天栏提示

「第 7 天 +1 个戒指、第 30 天 +2 个项链」这样写：

milestones = ["day=7;slot=ring;count=1", "day=30;slot=necklace;count=2"]

离线跨过的天数会补发；同一天同一类型写多条时以最后一条为准。

■ 游戏内命令

需要权限等级 2（单人开作弊 / 服务器 OP），和 /curios 系列命令同级。

/dailyslot status                          查看配置、激活状态、自己拥有的栏位
/dailyslot set <天> <数量> [栏位]           修改每日规则，立即生效并写回配置文件
/dailyslot rule add <天> <栏位> <数量>      追加里程碑
/dailyslot rule remove <天> <栏位>          删除里程碑
/dailyslot rule list                       列出里程碑
/dailyslot grant <目标> <栏位> <数量>       立即补发
/dailyslot convert <目标> <原栏位> <数量>   原生栏位 → 通用栏位
/dailyslot sync <目标>                     重新同步栏位数量
/dailyslot reset <目标>                    清空发放的栏位（栏内物品会掉落）

■ 成就

「渐强 / Crescendo」—— 挑战（史诗）成就，使用星陨激活时解锁，独立成就页。

■ 安装方法

1. 安装 Forge 1.20.1（47.x）；
2. 把 Curios API 与本模组 jar 一起放进 mods 文件夹；
3. 启动游戏，首次运行会生成 config/curios-star-fall-common.toml。

■ 兼容说明

· Curios 5.12.1 / 5.14.1 均已实测；理论上 5.7.0 以上都可用
· 与「旅行者背包」等同样使用 Curios 的模组共存正常
· 本模组会把 9 种原生栏位挂到玩家身上、基础数量设为 0，栏位全靠天数/里程碑长出来，
  不会额外白送栏位
· 从旧版本升级：存档里的解锁状态与栏位数量会自动迁移
```
